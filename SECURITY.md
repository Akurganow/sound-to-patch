# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Report a vulnerability privately through the repository's Security tab:
choose "Report a vulnerability". Do not open a public issue.

A useful report contains:

- the release or commit you tested;
- the command and the input that trigger the problem, or a minimal file
  that does;
- what happens and what you expected;
- the impact as you see it, for example code execution from a crafted
  preset or stem file.

The maintainer answers in the private report. Once a fix is released, the
advisory is published with credit to the reporter unless they ask
otherwise.
